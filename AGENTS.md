# Portfolio instructions

- Preserve the existing portfolio design when updating content. Keep the original hero, typography, colors, navigation, animations, layout and contact presentation unless the user explicitly asks to change them.
- Extend existing section patterns for new content. Do not interpret "update" or "next level" as authorization to redesign.
- Keep NDA work anonymous; preserve existing public project entries unless removal is requested.
- Ground NDA visuals in supplied screenshots or confirmed build workflows. An anonymous label does not justify invented product modules. Recreate the appearance without copying client branding, private data or proprietary visual layouts.
